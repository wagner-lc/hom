# HOM — Hotel Operations & Maintenance

HOM is a web-based hotel operations and maintenance management system developed with PHP, MySQL, JavaScript, HTML and CSS.

The project is based on a real system developed for daily use in a hotel environment. This public version was adapted as a portfolio demonstration, using fictional data and a separate database.

## 🔒 Demo Version

This repository contains a demonstration version of the application.

* No real hotel data is included.
* The database used by the demo is separate from the production system.
* Names, users and other potentially sensitive information were removed or replaced.
* Database credentials are not included in the repository.

## 📌 About the Project

HOM was created as a portfolio project to demonstrate the development of a real-world web application involving backend logic, database management, authentication, CRUD operations and operational workflows.

The original system was developed for practical use in a hotel environment and is used as a basis for the functionality presented in this public demonstration version.
